# Roadmap

## Now (0.2.x)
- CI on every push (pytest, 3 Python versions) and a demo smoke test.
- `list` and `stats` commands for reading an inbox back without grep.
- `export` to a single Markdown file or JSON for backup and migration.
- Security hardening of file paths: traversal/symlink guards and a strict filename whitelist for category files.
- `#tag` support in entries, with `search --tag` / `list --tag` filtering.
- Chinese template pack (`templates/zh/`) and a full protocol document (`docs/protocol.md`).
- Issue/PR templates and release hygiene (v0.2.0).
- A worked example inbox (`examples/sample-inbox/`, generated by `examples/generate-sample-inbox.py`) with a step-by-step walkthrough (`docs/walkthrough.md`).
- Search filters: `--since` and `--category`.
- `import` from an exported Markdown or JSON file (raw category files with `--category`), with format validation, duplicate skipping, and `--dry-run` preview.
- `doctor`: inbox health self-check (trailing newlines, md5 fingerprints, index consistency, file permissions) — read-only, exits 1 on any error.
- `backup` / `restore`: timestamped backups (all five files plus a `manifest.json` of md5 fingerprints) and restore with full integrity checks before any write, plus `--dry-run` validation.
- `stats` date ranges (`--since` / `--until`) and per-month counts.

## Next (0.3.x)
- `export` to a single offline-readable HTML file (table of contents, category anchors).
- Config file support (`~/.config/musings-inbox/config.toml`: default `--root`, default category).
- `search --regex` and `--case-sensitive`.
- `add` with multi-line input (stdin / editor) and batch append.
- `archive`: move old entries by date into `archive/` and update the index.
- Release v0.3.0.

## Later
- Optional summarization command that compresses older entries (kept out of the dependency-free core).
- Interop notes for more agent runtimes (skill-directory layouts beyond ClawHub-style).

Ideas and bug reports are welcome as issues. The core stays dependency-free:
anything that needs a network call or a model lives outside it.
