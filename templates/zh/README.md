# 中文模板包（templates/zh/）

`templates/` 英文模板的中文版：四个类别文件 + 一份索引，表头与用法说明均为中文。

## 文件

| 文件 | 用途 |
|---|---|
| `facts.md` | 事实：人物、日期、账号、做出的决定 |
| `preferences.md` | 偏好：喜欢 / 不喜欢、长期有效的做事指令 |
| `experience.md` | 经验：教训、复盘、验证过有效的做法 |
| `materials.md` | 素材：链接、引文、可复用的素材 |
| `index.md` | 索引：编号 \| 时间 \| 类别 \| 摘要 |

## 怎么用

1. 复制本目录的五个文件到你的收件箱目录（与英文 `templates/` 二选一即可）：
   ```bash
   cp templates/zh/*.md ./my-inbox/
   ```
2. 此后按 `docs/protocol.md` 的记入协议追加条目：
   `- [YYYYMMDD-NN] YYYY-MM-DD HH:MM — 正文`，索引同步追加一行。
3. 模板里的中文注释（`<!-- ... -->`）是给人看的说明，不会干扰条目解析——
   解析器只认以 `- [编号]` 开头的行；手写注释行会被跳过。

## 注意

- 时间戳只许来自当轮真实时钟读数，不许凭记忆估算；
- 追加前先确认文件末尾有换行，写后回读核验（CLI `add` 已内置这两步）；
- 正文里可用 `#标签`（如 `#灵感`），支持中文，大小写不敏感、自动去重；
  `search --tag` / `list --tag` 可按标签过滤；
- 完整协议见 `docs/protocol.md`，快速上手见 `SKILL.md`；
- 本仓库所有示例条目均为虚构，请勿写入任何真实个人信息。
