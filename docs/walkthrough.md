# Walkthrough — a worked example inbox

This page walks you through a complete musings-inbox session: filing
entries, searching with tags, listing, exporting, and verifying. It comes
with a ready-made inbox you can query right away.

## The sample inbox

`examples/sample-inbox/` is a **fully fictional** worked example — 12
invented entries spread across five days, covering all four categories and
English plus Chinese `#tags`. Nothing in it is real; it exists to
demonstrate the format and the commands. It was generated by
`examples/generate-sample-inbox.py` (deterministic — re-running it produces
byte-identical files) and passes `verify`.

Run everything from the repo root:

```bash
export PYTHONPATH=src   # or: python3 -m pip install -e .
```

## Step 1 — verify the inbox

```bash
python3 -m musings_inbox.inbox --root examples/sample-inbox verify
```

Output:

```
facts.md 35274c84afd3bae8a647c0128d5f63ac
preferences.md d48a0bbaef05b889e81e5a8aaeed49c8
experience.md dee258ba8e580995e77d664b9b197cea
materials.md e6fb70c779c7551aea16a9c2e83e1085
index.md 8b091bea6b44517b42c6b47b21465ce3
OK: index and content agree
```

`verify` prints an md5 fingerprint per file, then confirms the index and
the category files contain the same set of entry IDs. Any mismatch fails
loudly — that is the acceptance rule from `docs/protocol.md` §7.

## Step 2 — get the shape of the log

```bash
python3 -m musings_inbox.inbox --root examples/sample-inbox stats
```

```
total: 12
fact: 5
preference: 2
experience: 3
material: 2
per month:
  2026-10: 12
earliest: 20261020-01 2026-10-20 09:30 [fact] Ada opens her pottery workshop at nine every morning. #routine

```

Per-category counts, the earliest/latest entries in chronological order,
and the total entry-text characters.

## Step 3 — search with a tag filter

```bash
python3 -m musings_inbox.inbox --root examples/sample-inbox search workshop --tag routine
```

```
facts.md: - [20261020-01] 2026-10-20 09:30 — Ada opens her pottery workshop at nine every morning. #routine
```

A bare `search workshop` would also hit an untagged entry; `--tag routine`
narrows to entries carrying `#routine`. Tag matching is case-insensitive
(`--tag #ROUTINE` works the same) and Unicode-aware — the sample inbox has
a Chinese tag on the 2026-10-24 entry (`#灵感`).

## Step 4 — list by tag, category, and date

```bash
python3 -m musings_inbox.inbox --root examples/sample-inbox list --tag food
```

```
20261022-01 2026-10-22 09:00 [fact] The Blue Heron Cafe closes on Mondays. #food
20261023-01 2026-10-23 11:15 [fact] The night market opens at six on Fridays. #food
```

Filters compose:

```bash
python3 -m musings_inbox.inbox --root examples/sample-inbox list --category fact --date 2026-10-24
```

```
20261024-03 2026-10-24 11:00 [fact] 午后沿河散步是放空的好办法。 #灵感
```

## Step 5 — export for backup or migration

```bash
python3 -m musings_inbox.inbox --root examples/sample-inbox export --format json > sample-export.json
python3 -m musings_inbox.inbox --root examples/sample-inbox export  # one Markdown document on stdout
```

JSON is one object per entry (`entry_id`, `category`, `text`,
`timestamp`); Markdown is a header, a `total:` line, and one
`- [ID] timestamp [category] text` line per entry, chronological.

## Step 6 — file your own entries

Start a fresh inbox in your own directory and file a few musings (in a
real agent session, the timestamps come from a clock read taken in that
turn — see `docs/protocol.md` §2):

```bash
python3 -m musings_inbox.inbox --root ./my-inbox init
python3 -m musings_inbox.inbox --root ./my-inbox add --type fact --text "The corner bakery closes at six. #routine"
python3 -m musings_inbox.inbox --root ./my-inbox add --type preference --text "Prefer window seats. #travel"
python3 -m musings_inbox.inbox --root ./my-inbox search bakery --tag routine
python3 -m musings_inbox.inbox --root ./my-inbox list
python3 -m musings_inbox.inbox --root ./my-inbox verify
```

The entry line the tool writes looks exactly like the ones in the sample
inbox:

```
- [20261024-01] 2026-10-24 11:05 — The corner bakery closes at six. #routine
```

That is the whole loop: `add` → `search`/`list` to recall → `verify`
to trust. For the agent-side workflow (trigger words `Musings:` / `随想：`,
classification rules, the read-back discipline), continue with
`docs/protocol.md` (full reference) or `SKILL.md` (the short operational
edition).

## Regenerating the sample

The sample inbox is a build artifact, not hand-written data:

```bash
python3 examples/generate-sample-inbox.py   # rebuilds examples/sample-inbox/
```

The fixture list at the top of that script is the single source of truth;
the shipped files match it byte for byte (checked by the test suite).
